# Проект по обработке банковских операций

## Описание

Этот проект предназначен для обработки данных о банковских операциях. Он включает функции для фильтрации операций по статусу, сортировки их по дате, а также маскирования номеров карт и счетов.

## Функции

- `filter_operations`: Фильтрует операции по заданному статусу.
- `sort_operations`: Сортирует операции по дате.
- `mask_account_info`: Маскирует номера карт и счетов.
- `format_date`: Преобразует дату в формат "ДД.ММ.ГГГГ".
